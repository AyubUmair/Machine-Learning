# Logistic Regression with Scikit-Learn

This project demonstrates how to train a Logistic Regression classifier using **scikit-learn**. It visualizes the learned decision regions and classifies a simple two-dimensional dataset.

Unlike the previous project, which implemented Logistic Regression from scratch, this project uses the optimized implementation provided by scikit-learn.

---

## Features

- Binary classification
- Logistic Regression using scikit-learn
- Model training and prediction
- Decision region visualization
- Model coefficient extraction
- Built using NumPy, Matplotlib, and scikit-learn

---

## Dataset

A simple two-feature binary classification dataset containing six samples.

---

## Output

The program displays:

- Predicted class labels
- Learned model coefficients
- Decision regions
- Training data points

## Installation

Clone the repository:

```bash
git clone https://github.com/AyubUmair/Machine-Learning.git
```

Navigate to the project:

```bash
cd Machine-Learning/Logistic-Regression-with-Scikit-Learn
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the program:

```bash
python logistic_regression_scikit_learn.py
```
